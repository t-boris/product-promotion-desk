## 2. Что ждёт вас, чтобы приложение заработало с площадками

Ключи и токены не присылаются в чат. Они вводятся только в полях приложения и хранятся в его хранилище секретов.

| Площадка | Что создать у площадки | Где ввести в приложении |
|---|---|---|
| Telegram | бота у BotFather, добавить его администратором канала (и группы обсуждений, если есть) | новый аккаунт, под «How the app works with it» выбрать «Through a bot», токен бота |
| Страница Facebook | приложение Meta (бесплатно), токен страницы (Page access token) | новый аккаунт, «Through a Page (Facebook’s own API)», поле токена; шаги написаны в приложении |
| Threads | то же приложение Meta со сценарием Threads; токен и секрет приложения Threads (секрет используется один раз и не хранится) | новый аккаунт, «Through a developer app (Threads’ own API)» |
| Instagram | приложение Meta со сценарием Instagram, профессиональный аккаунт; токен на 60 дней из панели приложения («Generate token») | новый аккаунт, «Through a developer app (Instagram’s own API)» |
| Хранилище файлов | свой S3-бакет: Instagram и Threads берут картинки и видео только по адресу в интернете | Settings → «A place for files» |
| X | платное приложение разработчика (тип «Native App»), адрес возврата `http://127.0.0.1:47821/signin`, кредиты в Developer Console | аккаунт X: «Client ID», затем «Sign in with X» |
| Pinterest | приложение разработчика на бизнес-аккаунте с двухфакторной защитой; до Standard access пины видны только вам | аккаунт Pinterest: «App id» и «App secret key»; канал — адрес доски |
| LinkedIn | приложение, привязанное к странице LinkedIn; токен на 60 дней | аккаунт LinkedIn, поле токена; за неделю до конца срока приложение напомнит в Inbox |
| Почтовые ящики (IMAP) | app password у почтового провайдера (Gmail / iCloud / Fastmail / свой IMAP) | Accounts → Mailboxes → настройки IMAP и кнопка проверки |

Цены X, которые приложение называет до одобрения (прайс X от 28 ноября 2026): пост около $0.015, с ссылкой $0.20; ответ $0.01; числа под постом около $0.03 за 30 дней.

Факты, которые нужны от вас (D8 плана), если ещё не сказаны: профессиональный ли аккаунт Instagram; Facebook — страница или личный профиль; есть ли у канала Telegram привязанная группа обсуждений.
