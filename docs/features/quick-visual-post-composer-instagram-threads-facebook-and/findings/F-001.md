## Finding

DEC-030 says pictures were sent only as a Reddit post until a later slice. The spec assumes drafts with a picture go out through the existing pipeline to Instagram, Threads and Facebook. It does not state whether the sending path already supports picture posts on these platforms. The pipeline is out of scope, so if it does not, the saved drafts cannot be published.

> pictures went out only as a Reddit post until a later slice

## Possible interpretations

- The sending path already supports pictures for these platforms, so no work is needed
- Sending pictures to these platforms needs new work that is not in scope

## Resolution

Включить в охват доработку отправки картинок на площадки, где её нет, и добавить для этого отдельное требование. — see DEC-044.
