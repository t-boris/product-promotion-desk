## Finding

Existing drafts have a title and Markdown text. It is not defined how a quick post is stored: caption in the text field, an empty title, or the card parameters. It is also not defined how the review, approval and preview screens show a draft with no title.

> The composer has one picture slot and one caption field, and no mandatory title

## Possible interpretations

- Reuse the existing draft with an empty title and the caption as text
- Add a post-type field to the draft

## Resolution

В черновик добавляется явное поле типа (статья или быстрый пост). Подпись лежит в тексте, а параметры карточки — в структурированном поле черновика. — see DEC-046.
