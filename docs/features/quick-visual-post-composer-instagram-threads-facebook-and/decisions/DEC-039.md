## Context

The existing patterns keep AI controls per field.

## Alternatives

1. One action making caption and picture from a short description

## Decision

AI help in the quick-post composer stays as separate actions: one for the caption and one for the picture, as in existing fields. There is no single one-shot action.

## Reason

Owner chose more control and consistency with current patterns over a one-step action.

## Consequences

Existing PostDrafter and MakePicture patterns are reused; no combined flow is built.
