## Context

The request for more colour conflicts with the one-indigo-accent rule in the visual system.

## Alternatives

1. Colour only in the new composer and preview
2. One wider palette for the whole app
3. Composer first, palette later

## Decision

The app gets a theme system with several distinct themes: interesting dark and interesting light ones, not just plain dark/light. Themes may have an animated background as an option. The owner chooses a theme; the design system is updated to describe themes.

## Reason

The owner chose a theme system over restricting colour to the composer or widening a single palette.

## Consequences

visual-system.md must be revised to allow per-theme palettes; contrast must be rechecked per theme; animated backgrounds must be optional.
