## Context

The analyst role needs fresh data about what people care about now; the alternative was model knowledge only, possibly outdated.

## Alternatives

1. Model knowledge only, marked as possibly outdated
2. Model knowledge first, browser search added later

## Decision

The trend analyst gets current trends and interests by searching through the AI browser (DEC-035) when the owner asks for it, not only from model knowledge.

## Reason

The owner chose fresh data over speed and simplicity.

## Consequences

Trend help depends on the AI browser and is slower and can fail; a failure state must be handled and the owner can proceed without trends.
