## Question

Откуда берётся «захватывающая» картинка для быстрого поста?

## Why it matters

Вы написали, что картинка принципиальна и не может быть случайной, но не сказали, из чего она делается. От этого зависит весь композер: шаблоны с текстом, AI-иллюстрации или загрузка своих.

## Options

- **A**: Карточка-шаблон: приложение само рисует крупный заголовок на цветном фоне/градиенте (стиль, цвет, формат выбираются кликом).
- **B**: AI-иллюстрация: из короткого описания, предложенного по тексту поста, через существующий MakePicture (формат квадрат/высокий).
- **C**: Оба пути: по умолчанию карточка-шаблон, плюс кнопки «AI-иллюстрация» и «свой файл».

## Recommended

C — Шаблон даёт скорость и цвет сразу, а AI и свой файл уже частично есть в проекте и закрывают «захватывающие» случаи.

## Answer

C. Оба пути: по умолчанию карточка-шаблон, плюс кнопки «AI-иллюстрация» и «свой файл».
