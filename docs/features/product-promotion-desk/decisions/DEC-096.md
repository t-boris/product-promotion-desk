## Context

Owner requested all 6 Section 5 items in docs/design/remaining-work.md; this release implements the first three platform API features (Facebook Page hide/unhide comment, Threads & Instagram daily publishing limit, X standalone mentions in Inbox).

## Alternatives

1. Leave comment hiding to Instagram and Threads only; omit publishing quota display; keep X standalone mentions ignored.

## Decision

Add Facebook Page comment hide/unhide, Threads and Instagram daily publishing limit reporting in ChannelStatusCard, and X standalone mentions as native Inbox items via Connector.readInbox.

## Reason

Brings Facebook Page moderation to parity with Threads and Instagram, gives the owner live visibility into Meta 24-hour publishing limits before sending, and lets the owner answer X mentions outside their own threads through the existing Inbox pipeline without extra X API read costs.

## Consequences

FacebookPageConnector exposes hideComment (POST /{comment-id} is_hidden=true/false) and reads is_hidden; ThreadsApiConnector and InstagramApiConnector implement readPublishingQuota exposed via channels.publishingQuota and displayed in ChannelStatusCard; XApiConnector implements readInbox to collect standalone mentions as Inbox items with source=mention.
