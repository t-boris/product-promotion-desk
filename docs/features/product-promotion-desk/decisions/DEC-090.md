## Context

The plan's phase J says "pins with picture or video"; 0.85.0 built the picture. Pinterest's guide "Creating video Pins" (read 2026-11-28): register the upload (`POST /media`, `media_type: video`), send the file to the address and with the form fields the answer gives (no token there), ask `GET /media/{id}` until its status is `succeeded`, then create the pin with `media_source: { source_type: video_id, media_id, cover image }`. A cover image is required; the reference lets it be given as an address, as picture data, or as a moment of the video. Pinterest's own video specification: MP4, MOV or M4V, up to 2 GB.

## Alternatives

1. Keep a video for Pinterest itself: the plan's item stays unbuilt
2. Take a moment of the video as the cover (`cover_image_key_frame_time`): the application would choose the picture the pin is seen by
3. Give the cover as an address through the place for files: needs the owner's bucket for what the reference lets be sent as data

## Decision

A post to a Pinterest board through the API is one picture, or one video with one picture; with a video the picture is sent as the pin's cover (as data, the same picture file a picture pin sends). The connector registers the upload, sends the file with every field Pinterest gave and the file last, asks about the processing every five seconds for at most ten minutes, and only then creates the pin. Whatever stops before the pin is created is a failure with "Nothing was sent" (nothing is published by an upload); the creation of the pin keeps its "not known" outcome for a lost answer. The kind and the size of the video are checked before anything is asked. The form of a Pinterest post already asks for a picture, so the preview needs no new rule: the line "A video is not sent to Pinterest through its API" is gone.

## Reason

The plan asks for it and every request is in Pinterest's documentation. The owner's own picture is the cover because Pinterest's guide requires a cover and the form of a pin already requires a picture: nothing is chosen for the owner.

## Consequences

A video pin without a picture is refused with the reason. The length of a video (Pinterest: 4 seconds to 15 minutes) is not checked here: Pinterest's refusal is said. Unproven with a real Pinterest app: the upload to Pinterest's storage, the processing time, and that the cover given as data is taken (the guide shows an address, the reference documents the data form). Not built: several pictures in one pin (not in the plan).
