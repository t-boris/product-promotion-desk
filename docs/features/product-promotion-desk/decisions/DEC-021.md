## Context

The AI asked the owner the same things again on every account and site (a picture over a site's size limit, which fields may be edited), because the owner's answer was forgotten when the run ended.

## Alternatives

1. The owner confirms each rule in the pop-up: safer, but one more question for every answer.
2. Rules for every platform by default: simpler, but a rule learned on one site can be wrong on another.

## Decision

A rule kept from the owner's answer is a lesson: one short sentence, for one platform (default) or every platform, stored in the application. The AI saves it itself with remember_lesson right after the answer; the run shows it with Undo and Settings lists every rule for editing, switching off and removing. Every later signup or profile mission on that platform gets the rules in its brief and is told to follow them instead of asking. A rule never holds a password, a code or a personal value (refused when it contains a value the application types). For a size limit the application shrinks a copy of the approved picture with Electron's own image support (browser_upload shrink_to_kb); the original stays.

## Reason

Confirmed by the owner: the AI saves and the owner can undo, the default scope is the platform, and the app may shrink pictures itself. It removes repeated questions without a hidden memory: every rule is visible and editable.

## Consequences

New table agent_lessons (migration 208), lessons.* API, remember_lesson tool, ImageShrinker port. Not yet verified with a real engine run that asks and answers.
