## Decision

Support Pinterest multi-image carousel pins (2–5 JPEG/PNG images via API v5 multiple_image_base64) and Instagram API Stories (media_type=STORIES), custom picture alt_text (up to 1000 chars), and picture user_tags ([{ username, x, y }], up to 20). All Instagram options are persisted on drafts (migration 411), bound into the approval content hash, preserved across word rewrites while attachments still fit, enforced in core and connector pre-send validation, refused on replies and non-Instagram-API channels, and exposed in both the article DraftEditor and single-channel Instagram QuickComposer.

## Reason

Owner approved all six Section 5 platform capabilities (2026-11-28). Pinterest API v5 natively supports 2–5 image carousels through multiple_image_base64, and Instagram Graph API natively supports STORIES containers (single image or video without caption/alt_text/user_tags), image alt_text, and image user_tags. Binding all options in contentHash preserves the explicit-approval invariant (REQ-004).
