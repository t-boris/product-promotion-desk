## Context

REQ-005 requires persistent local workflows and recovery but does not define behavior when the user closes a window, quits the application, or logs into macOS. F-003 identifies this ambiguity.

## Alternatives

1. B. Keep automation running after window closure and optionally start the application automatically at macOS login.
2. C. Run automation only while an application window is open.

## Decision

Closing the last application window keeps automation running in the background. Explicit Quit stops all application automation until the user manually launches the application again. After macOS restart or login, the user must launch the application manually.

## Reason

The team selected option A. It supports prolonged background operation while making Quit an explicit stop and keeping startup under manual user control.

## Consequences

Update REQ-005 to distinguish window closure from Quit. Keep background status and pause controls accessible while windows are closed. Persist progress on shutdown and resume eligible work after manual launch, rechecking permissions and reconciling uncertain sends before retrying. No scheduled work runs during sleep, after logout, or while the application is stopped. Automatic startup at login is outside version 1.
