## Context

DEC-036 (accepted 2026-11-15) left a link out of an Instagram post because a link in a caption is not clickable, and put it as the last paragraph elsewhere. The owner's last Instagram post had a link in its draft and went out without it. The quick-post composer has no link field, so a quick post never had one unless typed into the caption.

## Alternatives

1. Write the address as plain text at the end of an Instagram caption (visible, not clickable; the owner chose the profile line instead)
2. Leave Instagram as it was, without a link (DEC-036)
3. Add the site when the post is rendered or sent instead of when it is saved (rejected: what the owner approves must be exactly what is sent; a switch changed after approval would change an approved post)
4. A switch for the whole application instead of for each product (the site belongs to the product)

## Decision

(1) The product keeps a switch "Put the website address at the end of every new post" (products.add_site_link, migration 310), on for every product, shown on the product's page when it has a website. (2) The core writes the product's website into the FIRST draft of a new standalone post when the draft has no link, where the platform takes a link in the text (Facebook, Threads, X, LinkedIn, Telegram) or points to the profile (Instagram). Never into a platform with a link field of its own (Reddit, Pinterest, TikTok, YouTube), never into a reply, never into a later draft: a link the owner takes out stays out. (3) Instagram's placement changes from "left out" to "in_bio": the address is not sent, the caption ends with the line "Link in bio" (not added twice if the caption says so, not added to a caption with no words), and the link lives in the account's profile, which the application never touches. (4) The composer's preview and limits count the site and the line before the post is saved (siteLinkFor, one function for the core and the screen). (5) A group version's first draft is given the site by its own platform; it does not count as changed by hand, and "Adapt with AI" keeps it. (6) Approvals of an Instagram post with a link are given again (the placement is part of the approval hash).

## Reason

The owner, 2026-11-21: "Why does it not add the link to my site at the end of every post?", then "Do #2 and as soon as possible" (link in bio on Instagram). The application never had a rule "always add the site"; a link was only there when the draft held one, and Instagram dropped it (DEC-036, alternative 2 rejected on 2026-11-15).

## Consequences

Every new Threads or Facebook post now ends with the site's address, so it counts against the text limit (Threads 500) and the disclosure of the author's connection to the product applies to it, as to any post that links the product. Posts already written are not changed. An approved Instagram post that has a link must be approved again. Reddit and other platforms with a link field are left alone on purpose. Not proven on the real Instagram: that the profile line reads well, and that the owner keeps the site in the account's bio. Instagram's own caption limit is 2,200 characters, 13 of them now go to the line when the post has a link.
