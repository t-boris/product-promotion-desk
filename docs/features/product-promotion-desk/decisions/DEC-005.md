## Context

The specification fixes only Electron, TypeScript, React and SQLite. The repository has no code, so every other library choice was open and needed the owner's approval.

## Alternatives

1. Use Node's built-in node:sqlite instead of better-sqlite3 (no native rebuild, still experimental).
2. Use pnpm instead of npm as the package manager.

## Decision

Use npm, electron-vite (Vite), React 19, strict TypeScript, better-sqlite3 (native module rebuilt for Electron), Vitest, ESLint and electron-builder.

## Reason

The owner approved the proposed toolchain: it is mature and well documented, and it keeps the core testable without Electron.

## Consequences

The core (src/core) must not import Electron so it can be tested headless with in-memory SQLite. Any further library beyond this list needs separate approval. The browser implementation for connectors remains subject to the real-site prototype in plan item I-3.
