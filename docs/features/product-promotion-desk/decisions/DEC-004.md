## Context

README states that the mandatory first platform remains open, while accepted DEC-001 and approved REQ-002 already establish Reddit as the first acceptance platform for Natal Mystic.

## Alternatives

1. Replace the outdated README statement with the explicit Reddit acceptance scope.
2. Remove the outdated statement and identify Reddit as the first platform, linking to DEC-001 and REQ-002 for acceptance details.

## Decision

Replace the outdated README statement with: “The first acceptance of Natal Mystic must be demonstrated on Reddit in one user-selected subreddit, including reading discussions, publishing user-approved standalone posts, and sending replies.”

## Reason

The team selected the explicit wording so that README directly communicates the settled acceptance scope and removes the contradiction without requiring readers to follow references.

## Consequences

Update README accordingly and resolve F-001 once the replacement is applied. DEC-001 and REQ-002 remain unchanged; this decision adds no new acceptance scope.
