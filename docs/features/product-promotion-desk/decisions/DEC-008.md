## Context

REQ-002 and DEC-001 require a live Natal Mystic run on Reddit in one user-selected subreddit: login, reading, an approved standalone post and replies. The records do not say who performs it or how the work is split into pull requests.

## Alternatives

1. One PR and no live Reddit run in this goal: stop at implemented with the live REQ-002 criteria unticked.
2. Several pull requests, one per wave, each merged and released separately.

## Decision

Deliver in one pull request with a commit group per plan item. Automated tests use recorded fixtures and a fake connector. After deployment the owner performs the login handoff, chooses the subreddit and approves the first real post and reply inside the application. The live REQ-002 acceptance criteria stay unticked until the owner confirms the result.

## Reason

The owner chose to complete the live acceptance together with the implementation. Nothing is published to a real community without the owner's explicit in-application approval of each action.

## Consequences

Onboarding must not publish test messages (REQ-002). The feature cannot be marked verified until the live run is confirmed. No credentials are requested or stored by the assistant; login happens on the site's page in the application's browser.
