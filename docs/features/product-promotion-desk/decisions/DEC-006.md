## Context

Verification requires walking through the running application in a MarkView browser tab, which opens web pages but not Electron windows. The records did not say how the UI would be reachable from a browser tab.

## Alternatives

1. Electron only: no web mode; the walkthrough would cover only the Vite dev server with a mocked backend.

## Decision

The same React UI is also served by the application on 127.0.0.1 with a random per-launch token and Origin checks. The UI talks to the core through one transport interface: IPC inside Electron, HTTP/WebSocket in a browser tab. Web mode is off by default in the packaged application and is switched on by a Settings toggle.

## Reason

The owner approved the loopback web mode so the real deployed application can be walked through like a user in a MarkView browser tab.

## Consequences

The server binds to 127.0.0.1 only, requires the per-launch token, rejects foreign Origins, and every outgoing action still passes the application authorization gate (REQ-004), so web mode adds no way to bypass approval. The UI must use the transport interface only and never import Electron APIs directly. Security for local data remains partial in the understanding and is covered here only for this local port.
