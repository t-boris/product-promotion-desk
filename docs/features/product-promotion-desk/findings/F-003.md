## Finding

Persistence and recovery are specified, but the operating lifetime of background automation is not. Closing a window, quitting the application, and logging into macOS lead to materially different monitoring and sending behavior. Define when automation remains active and when user action is required to resume it; this affects the process architecture and the user's expectation of unattended sending.

> Run persistent local background workflows with recoverable progress, visible failures, and user control.

## Possible interpretations

- Scheduled work runs only while the application process is running; the user must relaunch it after quitting or restarting macOS.
- Closing the interface leaves a background process running, with automatic startup after login.

## Resolution

Закрытие окна оставляет приложение работать в фоне. Команда Quit полностью останавливает работу. После перезагрузки пользователь запускает приложение вручную. — see DEC-003.
