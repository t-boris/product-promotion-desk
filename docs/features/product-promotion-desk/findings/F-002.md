## Finding

Analytics may be connected later, but the specification does not identify any supported business-event connection or ingestion workflow. Deferring user setup does not define implementation scope: a results screen alone cannot provide this capability. Specify one first-version ingestion route, or explicitly defer business-event integration while retaining available platform metrics.

> Promotion goals, available platform metrics, and connected business events can be inspected; analytics connection can be deferred.

## Resolution

В первой версии показывать только доступные метрики площадок. Подключение бизнес-событий перенести на следующую версию. — see DEC-002.
