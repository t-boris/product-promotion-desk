## Statement

The system shall let the AI propose the whole profile of a new account as a strategy for a stated purpose, and let the owner edit and approve it once, before anything is typed on a platform.

## Acceptance Criteria

- [ ] The AI proposes first name, last name, display name, user name, birth date, gender, place, about-text, website and a picture description at once, with the purpose, a strategy (audience and why this person fits it) and one reason per field.
- [ ] The proposal differs clearly from the other profiles on the same platform and follows the honesty rules of DEC-010 (no unsupported credentials, no real or famous names or likenesses, an adult of 18 to 80).
- [ ] The owner can edit every value and approves the profile once; an edit of an approved profile makes it a proposal again.
- [ ] The picture is made by an engine with an image tool from the description, or replaced by the owner's own file, and is shown to the owner before use.
- [ ] A registration or profile mission does not start without an approved profile, and it types only the profile's values; anything else it needs it asks the owner for.
