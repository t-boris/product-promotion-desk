## Statement

When an account has an e-mail address and a saved password and the owner asks for it, the system shall have the AI open the account's own browser on the platform's registration page, read the page, fill in every value it considers right, submit the form and, when the site asks a question or refuses something, decide the next step from what it sees on the page; only what a person alone can do (a CAPTCHA, a code sent to a phone) is handed to the owner.

## Acceptance Criteria

- [ ] The assistant starts only when the owner presses a button for that account, works only on the registration page of the account's platform in the account's own browser, and stops at once when the owner takes the browser (REQ-004).
- [ ] Before every step and after every submit the AI is given what the page shows (text, the messages of the site, a screenshot, the requests the page made, DEC-016) and chooses the next step from it; it never repeats a submit without having changed something.
- [ ] The AI answers with actions (fill this field with this value, click this button, choose this option) and the application carries them out; the AI never holds the browser itself, and an action that names a field of another site or a password field it was not given is refused.
- [ ] The e-mail address and the saved password of the account are typed by the application from the account and the vault; the AI sees a placeholder, and the password never appears in a log, a report or an AI prompt (DEC-014).
- [ ] The other values (name, birth date, gender, display name, user name) come from the account's role and the product passport, or are proposed by the AI; each value the AI made up is recorded on the account and shown to the owner.
- [ ] A refusal by the site that a different value can fix (an e-mail or name that is taken, a weak password, a name the site refuses) is fixed by the AI with a different value, up to a small number of attempts; the same refusal again stops the assistant.
- [ ] A CAPTCHA, a code sent to a phone, a code sent to an e-mail the application cannot read, an identity check or an account the site blocks is handed to the owner with what the AI saw and what it tried, in plain words.
- [ ] When the registration is done the application checks the sign-in itself and shows the result; the account does not count as signed in because the AI says so.
