## Statement

Provide a personal local workspace that keeps promotion data independent of the AI engine and makes activity and available results inspectable. Version 1 retains promotion goals and displays available platform metrics, distinguishing unavailable metrics from zero values without implying measured business conversions. Business-event integration is deferred beyond version 1; version 1 excludes business-event ingestion and analytics connections. A later version requires a separate ingestion and attribution contract for business-event integration.

## Acceptance Criteria

- [ ] Each user operates an independent macOS installation with their own data and accounts.
- [ ] The user can select and verify an installed Codex or Claude Code engine; changing engines preserves product knowledge and history.
- [ ] Product data can be entered manually when the AI engine is unavailable.
- [ ] Work areas expose attention items, products, channels, opportunities, publications, results, logs, and settings.
- [ ] Version 1 retains promotion goals and allows the user to inspect them.
- [ ] Version 1 displays available platform metrics.
- [ ] Results distinguish unavailable metrics from zero values.
- [ ] Version 1 excludes business-event ingestion and analytics connections.
- [ ] Version 1 results do not imply that business conversions have been measured.
- [ ] Business-event integration is deferred beyond version 1 and requires a separate ingestion and attribution contract before implementation.
- [ ] Action history explains what was sent, where, when, and on what basis.
