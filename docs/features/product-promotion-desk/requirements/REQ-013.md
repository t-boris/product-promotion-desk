## Statement

The system shall connect the owner's mailboxes read-only, show in one inbox every message that concerns the owner's accounts, and give each message a way to open it in the owner's own mail service.

## Acceptance Criteria

- [ ] A mailbox is connected with an application password over IMAP; the application shows whether it is reachable and when it was last checked, and never sends, deletes, moves or marks any message.
- [ ] One inbox lists the messages of all connected mailboxes that concern the owner's accounts: those addressed to an address the application proposed for an account (an alias or an address on the owner's domain) and those sent from a platform the owner has an account on. The rest of the mailbox is not read into the application.
- [ ] Each message shows its account, sender, subject, date and plain text; images and remote content are never loaded, and links are shown as text.
- [ ] The inbox can be filtered by account and by platform and shows which messages are new.
- [ ] A message can be opened in the owner's own mail service from a button (a direct link for Gmail, the mail service's address for the others).
- [ ] Only the headers and a short preview of a message are kept in the application's database; the full text is fetched from the mailbox when the message is opened and is not stored.
- [ ] A verification code or confirmation link in a message addressed to a new account is shown next to the account being created; a link is opened only when the owner presses it.
- [ ] Mail text is data: it is never sent to the AI engine and never acted on.
