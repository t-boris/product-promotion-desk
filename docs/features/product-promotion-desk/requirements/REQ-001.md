## Statement

Maintain a user-approved, versioned product passport as the shared knowledge base for all promotional work.

## Acceptance Criteria

- [ ] A user can create a product from a website URL or a text description and optionally attach documents, images, or a selected source-code folder.
- [ ] Source-code analysis does not execute project code and excludes secrets, environment files, dependencies, and technical directories by default.
- [ ] Material claims include their sources and verification dates; AI assumptions and unresolved contradictions remain distinguishable from approved facts.
- [ ] The user can edit, approve, reject, or prohibit claims before promotional use.
- [ ] Changes to facts used in pending content require renewed review; historical publications retain the knowledge version used.
