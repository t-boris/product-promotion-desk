## Statement

Run persistent local background workflows with recoverable progress, visible failures, and user control.

## Acceptance Criteria

- [ ] Products, accounts, channel configuration, completed analysis stages, pending work, and action history survive application restart.
- [ ] Scheduled work resumes after restart, sleep, or connection loss without blindly repeating uncertain sends.
- [ ] An expired login or CAPTCHA requests user participation and suspends affected operations.
- [ ] A channel failure does not stop other channels, and an AI-process failure does not close the application.
- [ ] The user can pause automation from every working screen, and each run exposes its time, status, and short result.
